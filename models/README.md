# Modellek

A SmartBlur az alábbi előre betanított modelleket használja:

- `license_plate.pt` – rendszámfelismerő YOLO modell.
- `face_detection_yunet_2023mar.onnx` – YuNet arcfelismerő modell.

A modellek forrásai:

- https://huggingface.co/joker5914/yolov8n-license-plate
- https://github.com/opencv/opencv_zoo
